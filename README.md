# ⏳ Countdowns Extension  
### [🚀 Live Demo](https://abhinav-dev0.github.io/countdowns-extension/)
**Countdowns Extension** is a lightweight browser add-on that helps you track upcoming events right on your new tab page.  
Built with **HTML**, **CSS**, and **JavaScript**, it focuses on simplicity, clarity, and speed.

---

## 🧭 Features

- Add multiple countdown events with custom names and dates  
- See real-time timers update seamlessly  
- Minimal, distraction-free design  
- Works offline — no backend or cloud sync  
- Blazing fast and privacy-friendly

---

## 🧩 Tech Stack

- HTML5  
- CSS3  
- JavaScript  
- Chrome Extension Manifest v3
